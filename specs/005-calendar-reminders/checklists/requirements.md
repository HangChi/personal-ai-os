## 关键风险已显式记录

- [x] CHK014 **扫描漏提醒**风险已记录：窗口左边界必须回收，否则「提前量 < 扫描间隔」时会永久丢提醒（data-model.md）
- [x] CHK015 **重启丢提醒**风险已记录：因此调度必须是 DB 状态驱动而非内存定时任务（research R-02）
- [x] CHK016 **并发双写**风险已记录：幂等靠数据库唯一键，不靠「先查再插」（research R-04）
- [x] CHK017 **漏发事件**风险已记录：任务提醒采用扫描兜底而非事件通知，任何漏发都会在下一轮补上（research R-05）
- [x] CHK018 **前置重构的回归**风险已记录：Phase 1 完成后阶段 2 的 21 个测试必须全绿；行为变化按回归处理，修代码而不是改测试（tasks.md Phase 1）
- [x] CHK019 `MONTHLY` 的边界语义（无该日取月末）已明确记录为**有意设计**而非笔误（data-model.md）
- [x] CHK020 **提醒物化的不可逆取舍**已记录：物化带来「已读状态」与审计，代价是提醒时刻精度受扫描间隔限制（research R-02）
