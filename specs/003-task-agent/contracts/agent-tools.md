# Agent 工具契约：阶段 2

模型可通过 8 个工具操作任务。**工具集合中不存在任何「确认」类工具** —— 这是本阶段最关键的安全不变量（SC-003）。

## 通用约定

- 工具返回值统一为 JSON 文本，结构为 `ToolExecutionResult`：

```json
{ "status": "OK", "message": "已创建任务「交周报」", "data": { }, "confirmationId": null }
```

| `status` | 含义 | 模型应如何应对 |
|---|---|---|
| `OK` | 执行成功 | 向用户复述结果 |
| `REQUIRES_CONFIRMATION` | 已生成待确认操作，**尚未执行** | 告知用户「需要在界面上确认」 |
| `DUPLICATE` | 本轮内该操作已执行过，未重复执行 | 直接复用首次结果，不要重试 |
| `REJECTED` | 入参非法 | 向用户说明原因并修正参数 |
| `ERROR` | 执行出错 | 说明失败，不要编造成功 |

- 每个工具都可能返回 `REJECTED`；模型 MUST NOT 把 `REJECTED` / `REQUIRES_CONFIRMATION` 复述成「已完成」。
- 所有写操作在工具内部经 `TaskService` 完成，工具**不直接访问数据库**（FR-005）。

## 工具清单

### 1. `createTask` — 创建任务（不需确认）

| 参数 | 必填 | 说明 |
|---|---|---|
| `title` | 是 | 1~200 字 |
| `description` | 否 | ≤ 2000 字 |
| `priority` | 否 | `LOW` / `MEDIUM` / `HIGH`，默认 `MEDIUM` |
| `dueAt` | 否 | ISO-8601 时间字符串 |

### 2. `findTasks` — 查询任务（不需确认）

| 参数 | 必填 | 说明 |
|---|---|---|
| `keyword` | 否 | 匹配标题或描述 |
| `status` | 否 | `TODO` / `DOING` / `DONE` |
| `limit` | 否 | 默认 20，上限 50 |

### 3. `getTask` — 查看单个任务（不需确认）

| 参数 | 必填 | 说明 |
|---|---|---|
| `taskId` | 是 | 任务 UUID |

### 4. `updateTaskDetails` — 改标题/描述（不需确认）

| 参数 | 必填 | 说明 |
|---|---|---|
| `taskId` | 是 | |
| `title` | 否 | 新标题 |
| `description` | 否 | 新描述 |

> 仅限「非关键字段」。截止时间与优先级各有专用工具，且需要确认。

### 5. `scheduleTask` — 改截止时间（**需确认**）

| 参数 | 必填 | 说明 |
|---|---|---|
| `taskId` | 是 | |
| `dueAt` | 否 | 新的截止时间；省略表示清除 |

### 6. `setTaskPriority` — 改优先级（**需确认**）

| 参数 | 必填 | 说明 |
|---|---|---|
| `taskId` | 是 | |
| `priority` | 是 | `LOW` / `MEDIUM` / `HIGH` |

### 7. `setTaskCompleted` — 标记完成 / 取消完成（不需确认）

| 参数 | 必填 | 说明 |
|---|---|---|
| `taskId` | 是 | |
| `completed` | 是 | `true` 标记完成，`false` 取消完成 |

> 不纳入确认范围的理由见 research.md R-07：可逆、非破坏，且是最高频的助手动作。

### 8. `deleteTask` — 删除任务（**需确认**，可批量）

| 参数 | 必填 | 说明 |
|---|---|---|
| `taskIds` | 是 | 1~50 个任务 UUID |

> 传入多个 id 即批量删除，同样需确认（FR-009）。超过 50 个 → `REJECTED`，提示拆分。

## 需确认操作的返回示例

模型调用 `deleteTask(["0f2b…"])`：

```json
{
  "status": "REQUIRES_CONFIRMATION",
  "message": "删除操作需要你确认。我已在界面上生成待确认事项：「删除 1 个任务：交周报」，请确认后执行。",
  "data": null,
  "confirmationId": "9c1e…"
}
```

**注意**：工具返回中**没有** `token`。令牌只经 `GET /api/v1/agent/confirmations` 下发给人类（FR-012）。

## 参数校验

所有工具入参在进入业务逻辑前校验（FR-006）。校验失败返回 `REJECTED`，且**不产生任何数据库写入**（SC-006）：

| 情形 | 提示 |
|---|---|
| 标题为空 / 超过 200 字 | 「标题不能为空」/「标题长度不能超过 200」 |
| 优先级不在枚举内 | 「优先级只能是 LOW/MEDIUM/HIGH」 |
| 截止时间无法解析 | 「截止时间格式不正确，请使用 ISO-8601」 |
| 任务不存在 | 「任务不存在：xxx」 |
| `taskIds` 为空 / 超过 50 | 「至少需要一个任务标识」/「一次最多删除 50 个任务」 |

## 幂等

- 同一轮对话内，**同一工具 + 同一参数**重复调用 → 第二次返回 `DUPLICATE` 并附首次结果，**不重复执行**（FR-014）。
- 跨轮次的相同调用 → 正常执行（用户可能真的想建两个同名任务）。
