## Notes

1. **全高高度 136px 是实测值**：header 60 + footer 60 + main padding-top 16。改 App.vue 骨架（如页脚高度）需同步改这里——已在 CSS 注释标明。

4. 不删任何会话数据；测试数据清理在验收后单独问用户。
