# 新建任务表单排版优化

日期：2026-11-06。依据用户提供的新建任务截图，局部改善字段排版与操作体验，沿用整体配色。

## 用户场景与验收

1. 快速创建：标题置于首行，截止时间与优先级对齐，标签独占整行；删除底部重复提示及冗长可选说明。空标题不能创建，提交中禁止重复提交，失败和取消不丢草稿。
2. 按需配置：项目、父任务、重复规则放入可键盘操作的「更多设置」，默认收起；添加子任务时自动展开并展示父任务。折叠不丢选项，已选设置有简短摘要。
3. 有效约束：保留同项目一级父任务筛选、父任务与重复任务互斥、周期任务截止时间校验及重复时区输入，不改变请求格式或后端行为。
4. 自适应：桌面使用协调的两列布局，手机单列；统一标签、控件、按钮间距，弹窗内部可滚动，底部操作易于访问，不横向溢出。验证深浅主题。
5. 顶部搜索：根据用户追加要求，将顶栏全局搜索从胶囊改为圆角矩形；保持颜色、搜索、清空、快捷键和手机自适应行为。

## 边界

不新增运行时依赖，不调整全局色彩、字体或其他模块；共享组织字段只精简标签并补充关联约束的即时提示，编辑任务的功能与布局不重做。不读真实环境配置或写入真实业务数据。

## 验证

组件覆盖字段提交、空标题、重复校验、提交中保护、折叠保值和子任务展开；隔离 API 浏览器检查桌面与手机、深浅主题、键盘、下拉、日期及按钮状态。前端检查与 Java verify 按仓库门禁执行；源码变更完成后同步迁移候选登记，保持冻结清单、SQL、发布门禁和候选状态。
