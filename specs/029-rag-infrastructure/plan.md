# 分阶段实施

1. Redis 二级共享嵌入缓存：命名空间、TTL、超时、故障降级、真实容器验证。
2. RabbitMQ 数据库任务通知：持久队列、确认、仅 ID 通知、轮询兜底。
3. S3 附件适配：配置化后端、原本地文件兼容、服务端读取与清理、兼容服务验证。
4. OpenSearch 可恢复投影与双通道召回：数据库变更 outbox、重建、删除一致性、过期命中校验。
5. RAG 查询改写/多路融合/重排/精审：阶段预算、trace、降级与评测。
6. 来源治理与冲突：空间、元数据、入库事实审查、冲突记录/人工处理、问答和聊天保护。
7. 前端、API 文档、集成部署配置、全量回归与合并。

复杂性说明：使用可选适配器，不拆业务微服务、不引分布式事务。新服务不替代数据库的幂等、租约与事实来源。
