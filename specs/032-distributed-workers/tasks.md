# 分布式后台工作与通知

用户要求按顺序实现独立索引 worker、资料冲突审查、OpenSearch Outbox 同步、
多渠道通知和多实例广播；外部渠道已选择通用 Webhook。保持逐条“知道了”，阶段性提交。

- [x] 数据库协调：跨进程文档租约与最终写入 fencing、共享模型并发和限流。
- [x] 独立索引角色：原子并发准入、Rabbit 消费隔离、独立运行和状态管理。
- [x] 独立审查角色：版本及领取身份校验、独立配额、持久化唤醒通知。
- [x] 搜索同步角色：Outbox 原子领取、条件回执、重试、Rabbit 唤醒和数据库补偿。
- [x] 通知角色：持久 Webhook 投递与签名、限时重试、渠道独立处理。
- [x] 广播：Rabbit fanout 与每实例独立订阅队列，已读和到点事件唤醒本实例 SSE。
- [x] 隔离环境端到端验证、完整回归与部署说明。

数据库保存任务与投递状态，MQ 消费确认不替代业务成功或用户已读。
不配置或访问用户未提供的 Webhook 目的地址；使用本地接收器完成真实协议测试。
