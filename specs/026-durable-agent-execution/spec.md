# 持久化 Agent 执行与可见活动

用户目标：中断后可继续；实时看清工具执行和回答生成；人工确认能核对操作对象与影响。

- 浏览器断开不能取消执行，刷新后按游标追赶同一任务，不重新提交用户消息。
- 显式停止持久化进度；继续沿用执行身份与写工具幂等键。
- 服务重启恢复结果确定的任务；有未决工具副作用时阻止自动重试。
- 实际工具开始、结束、待确认、失败与耗时应即时可见；不展示隐藏推理，也不虚构命令执行。
- 人工确认直接以内联提问卡片展示服务端摘要、影响数和期限；单次点击允许或拒绝，不弹二次确认。暂不选择保留待确认。
- 完成全部确认后续跑；仍有未完成计划时保留继续入口。

验收覆盖：无浏览器执行、游标追赶与去重、停止恢复、重启恢复、未知结果阻断、确认前阻断及拒绝后恢复、工具活动顺序、前端重连、授权卡片过期与并发保护。
