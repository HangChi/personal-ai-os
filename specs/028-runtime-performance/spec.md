# 运行效率与后台任务

延续单用户模块化单体，不引入 Redis 或独立消息队列。
按顺序交付：可选监控 → 后台执行准入与事件传输 → 有指标的可选本地缓存 → 数据库后台任务。
每阶段独立验证并提交。

- 监控不得公开业务接口或敏感配置。
- 后台执行直到真正结束才释放并发许可；重试不重复消耗许可。
- 合并事件保持顺序，断线后能按持久化游标恢复，浏览器断开不取消任务。
- 缓存必须有容量、失效策略、命中率，默认关闭；聊天回答和确认状态不缓存。
- 后台任务使用短事务领取，模型调用在事务外；具备租约、进度、重试上限与重启恢复。
- 保留原有同步接口兼容性；异步接口新增，不静默改变原调用语义。
