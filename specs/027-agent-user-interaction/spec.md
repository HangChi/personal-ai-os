# Agent 澄清问题与执行中的跟进消息

- 提供 askUser 工具：一个明确问题、最多四个带说明的选项，始终允许自由输入。
- 提问后进入 WAITING_USER，在模型或工具边界停止推进；回答后沿用原执行身份继续。
- 问题、回答和队列持久化，刷新不丢失；相同回答重试不重复启动。
- 执行中保持输入可用，按设置页选择的 QUEUE（当前任务完成后按序执行）或 STEER（安全边界调整当前任务）直接处理新消息；发送框不再提供模式选择。
- 不取消正在执行的工具；引导在下一次工具或模型调用前、或回答增量到达时交还控制并继续。
- 队列展示待处理内容，可取消、编辑或转为当前对话的引导；编辑保留位置与附件，转为引导复用原记录避免重复执行。提问和人工确认期间不消耗队列。
- 意图回答与引导不代表危险操作的人工授权。
- 网络失败重试复用消息标识，不重复排队，文本和附件保持可重试。
