# 实施计划

## 设计取舍

这是个人日常工作的工具型工作区。保留紫蓝主色及现有全部语义色，用统一的窄导航、清晰页头、内容标签和紧凑工具区建立层级。系统字体承担中文标题/正文，现有等宽字体仅用于技术标识。无需新增字体、图标库或运行时依赖。

页面先回答“正在处理什么”，再提供一个主要操作；低频配置以折叠区、对话框和设置入口承接。知识库保留资料与长期记忆的边界，使用共同入口而不混合数据。运行中心只读聚合活动与用量。设置分组有说明，偏好自动保存，外部配置明确保存。

## 技术

- Vue / Pinia / Element Plus 原生组件；路由 query 保存可分享位置，旧路径重定向兼容。
- 复用业务组件和已有偏好；集中管理路由分组，避免重复导航定义。
- 公共样式只负责布局工具类、可访问性与触控尺寸，不覆盖现有颜色令牌。
- 新增交互有组件回归测试；Playwright 使用完整 mock API、独立构建和本机临时预览。
- 保持迁移冻结清单不变，源码提交后登记增量 SHA/哈希，发布门禁保持未关闭。

## 验证

前端全套门禁；桌面/手机、深浅主题、导航回退、设置持久化、创建/编辑/取消、通知、错误与空态；必要的后端验证及迁移台账检查。浏览器结果明确为模拟数据验证，不冒充后端端到端结果。
