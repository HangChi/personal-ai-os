# 工作区界面整合

## 用户目标

逐个优化已有模块及设置子模块的排版、按钮与交互，整合重复入口；保留现有整体配色、深浅主题、业务能力与历史链接。

## 范围

- 主导航：知识与记忆统一入口；活动与用量统一为运行中心；维护与恢复归入设置。
- 设置：按连接、使用偏好、系统维护组织，补充真正生效的视图、布局、提醒与快捷键设置。
- 工作区：列表优先，创建与复杂操作渐进展开；统一标题、工具条、表单、空态、错误反馈和手机布局。
- 覆盖总览、对话、任务、日程、知识库全部子页、定时报告、运行中心、设置全部子页与登录/搜索辅助页。

## 验收

1. 旧 `/memory`、`/usage`、`/maintenance` 链接及原有 query 能定位新入口。
2. 偏好真实持久化；通知只由点击申请；删除、导入及恢复边界不变。
3. 390px 和 1440px 下无页面横向溢出，表格可在容器内滚动，所有操作可用键盘访问。
4. 原有颜色变量及主题色值不变，尊重 reduced-motion。
5. 类型、lint、格式、逻辑/组件测试、生产构建与隔离浏览器检查通过；不访问真实业务数据。
