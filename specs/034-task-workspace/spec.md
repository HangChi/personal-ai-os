# Feature Specification: 今日工作台与项目任务

**Feature Branch**: `go`（沿用当前工作分支，不修改既有迁移证据）
**Created**: 2026-11-06
**Status**: Implemented and locally validated（尚未部署到现有运行环境）
**Input**: 用户要求开始实现「今日工作台」和「项目、子任务和周期任务」。

## User Scenarios & Testing

### User Story 1 - 今日行动入口 (Priority: P1)
用户打开首页即可处理今天到期和往日逾期的任务，查看今天日程、待确认操作和未结束的最近执行。
**Why this priority**: 从总览数字进入实际行动。
**Independent Test**: 创建今日/昨日/明日任务，首页只在对应分组显示前两项，完成后即时刷新。
**Acceptance Scenarios**:
1. Given 本地日期跨日，When 刷新首页，Then 使用本地自然日边界，分组无重叠且计数不受任务页筛选影响。
2. Given 某数据源失败，When 首页加载，Then 该区显示错误与重试，其他区仍能使用。
3. Given 待确认或暂停执行，When 点击，Then 回到对应会话的现有恢复/确认界面，不自动执行。

### User Story 2 - 项目和子任务 (Priority: P1)
用户新建、重命名、归档或恢复项目，将任务归入项目，并在父任务下拆出一级子任务。
**Why this priority**: 以项目组织工作，保持简单明确的完成关系。
**Independent Test**: 新建项目和父子任务，筛选项目，完成子任务后再完成父任务。
**Acceptance Scenarios**:
1. Given 未完成子任务，When 完成父任务，Then 拒绝并给出可操作原因。
2. Given 存在子任务，When 删除父任务或改变父任务项目，Then 拒绝；不静默级联删除或移动。
3. Given 已归档项目，When 新增关联，Then 拒绝；现有任务仍可处理，项目可恢复。

### User Story 3 - 周期任务 (Priority: P1)
用户设置每天、工作日、每周或每月重复，完成本期后自动得到下一期。
**Why this priority**: 降低重复录入，明确每期完成记录。
**Independent Test**: 月末建立每月任务，完成后检查下月月末，重复完成和重新打开再完成只生成一期。
**Acceptance Scenarios**:
1. Given 多次或并发完成，When 写入，Then 本期与下一期在同一事务保存且最多生成一次。
2. Given 月末或夏令时，When 生成下一期，Then 保持规则时区的本地时间、月末截断后保留原始日锚点。
3. Given 长期逾期任务，When 完成，Then 从原到期日推进一周期，保留遗漏期可见性，不静默跳过。

### Edge Cases
- 不允许自引用、两级以上子任务、跨项目父子、把已完成任务设为新父任务。
- 周期任务要求截止时间与有效时区；首版不允许周期任务同时具有父任务或子任务。
- 不提供项目物理删除；归档可恢复。任务删除遵循现有人工确认。
- 导入导出保持项目、层级、规则与生成标记；旧备份仍可导入。

## Requirements
### Functional Requirements
- **FR-001**: 首页按独立区块加载今日任务、逾期任务、日程、确认和最近未结束执行；每区可重试。
- **FR-002**: 有界列表需显示总数及更多入口，不把截断列表当作全量。
- **FR-003**: 项目名称去首尾空白，必填且最多 100 字；描述最多 2000 字；支持归档恢复。
- **FR-004**: 任务可关联一个项目和一个同项目的根父任务；仅一级子任务。
- **FR-005**: 存在未完成子任务时不能完成父任务；存在任何子任务时不能删除父任务或移动项目。
- **FR-006**: 规则包括不重复、每天、工作日、每周、每月；周期任务与子任务互斥。
- **FR-007**: 生成下一期必须原子且幂等，保留标题、描述、优先级、项目、标签、时区和月锚点。
- **FR-008**: 原有任务、确认、提醒、搜索和备份行为需兼容，不修改原迁移文件。
- **FR-009**: 增加核心边界、并发、备份和组件测试，并实际执行可用检查。
### Key Entities
- Project：名称、描述、归档状态、创建和更新时间。
- Task：项目关联、父任务关联、周期规则、时区、月锚点和本期已生成标记。
- Today：本地日期窗口下的独立行动分组，不持久化重复快照。

## Success Criteria
### Measurable Outcomes
- **SC-001**: 用户从首页一次点击可完成任务或回到对应会话处理确认/恢复。
- **SC-002**: 10 次重复完成与并发完成均只新增一条下一期任务。
- **SC-003**: 父子关系不合法时所有入口均拒绝且不产生部分写入。
- **SC-004**: 新旧备份均可导入，新增字段完整往返。

## Assumptions
- 本地单用户，沿用认证与现有视觉系统；不引入新运行时服务。
- 首版不含自动模型晨报、复杂依赖图、无限层级、节假日历或定时铺满未来实例。
- Java 稳定后端与 Go 候选后端同时支持；033 的冻结基线及验收结果不自动更新。
