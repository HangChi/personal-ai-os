# 037 · 对话来源展示与知识增强上下文

## 用户目标

保留整体配色，删除重复提示，将检索详情和引用来源合并；修复知识增强下日程修改等连续追问被资料澄清提前截断的问题。

## 验收场景

- 流式和完成态的来源始终跟随对应助手回复，固定在正文下方；开始下一轮或切换会话不串轮。
- 有来源时显示紧凑的去重来源入口，展开后可查看编号、片段、外链和检索过程；保留内联引用预览和安全链接校验。
- 普通零命中不显示空来源卡片；真实冲突、澄清、核对失败与降级原因可按需查看。
- 知识增强使用有界历史理解指代。日程续改进入原有对话和工具流程；知识追问补全检索问题。资料冲突保护保持有效。
- 路由只读、无工具；历史不能作为知识证据；无效输出、超时或异常降级为正常对话并给出真实警告。
- 独立知识问答保持严格资料语义，不改变数据库结构、业务数据、现有配色或发布门禁。

## 范围

Vue 对话组件与状态恢复；Java 与 Go 对话增强接线及检索路由；回归测试、隔离浏览器验证、迁移来源登记。不连接真实模型或日程执行验证，不推送远端。
