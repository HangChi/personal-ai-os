# 使用指南

Personal AI OS 面向单用户自托管；初次安装先看[快速开始](../README.md#快速开始)与[配置](configuration.md)。Java 和 Go 共用界面，但 Go 仍为未获生产批准的候选，启动开关见其[指南](../backend-go/README.md)。

## 配置好模型

在设置中核查聊天模型、可用模型档案和嵌入配置。任务/日程等本地操作不要求模型可用；AI 对话、图片提取、知识嵌入和 RAG 辅助阶段需要相应能力。聊天与嵌入是独立客户端；更换嵌入模型前先安排隔离重建，同维度不代表可混用旧向量。

认证开启后先登录。公网必须使用 HTTPS/认证/CSRF，不能沿用无认证本地配置。[安全策略](../SECURITY.md)说明数据会向哪些可选服务发送。

## 与 Agent 协作

新建会话，说明目标、时间和约束，例如“把下面三件事整理成待办，截止到周五”。相对日期采用服务器日历时区，应与使用者一致；不明确的时间/对象可由助手询问。

对话中可查看计划、工具轨迹和来源。计划完成标签表示执行状态，实际业务写入仍以成功工具结果与业务页面为准。工具循环有预算，达到限制会停止，已完成操作不会撤销。

| 操作 | 适用情况 |
| --- | --- |
| 回答问题 | Agent 需要补充信息，提交澄清答案 |
| 确认/取消 | 高风险写操作等待人工决定；模型不能自行批准 |
| 停止 | 显式取消后续执行，不回滚已完成工具 |
| 继续 | 在允许的中断状态恢复；未知写/待确认可能阻止恢复 |
| 仅总结 | 汇总已完成工作，不调用工具，不解除原执行阻塞 |
| 排队 | 当前 Run 正常完成后发送下一条；等待/中断不自动派发 |
| 引导 | 在当前工具结束后的安全点加入新要求，不抢占已发请求 |

刷新或断网不会自动停止持久 Run；重新打开会话读取运行状态即可。确认完成后的收尾不会重新让模型执行原任务。详见[Agent 机制](agent-runtime.md)。

输入 `/` 查看当前[快捷指令](chat-commands.md)。直接工具操作也遵守服务端权限、幂等与确认；网络结果不明时先查运行中心和目标业务数据，不反复点击写入。

## 知识库与问答

1. 上传 Markdown、TXT、带文本层 PDF、DOCX 或图片。单文件默认 5 MiB；图片需要视觉模型，扫描 PDF 不自动 OCR。
2. 等待同步上传完成或异步任务 SUCCEEDED；失败时先核查解析/嵌入，不把列表出现文档当成全部索引成功。
3. 在知识库搜索查看片段，或使用问答/对话知识增强。搜索与增强问答路径不同，后者可能额外改写、重排和核对证据。
4. 点击引用核对具体片段、章节、来源与适用范围。命中文档不保证涵盖全部答案，READY 也不是事实绝对正确。
5. 在治理中维护知识空间、来源版本/有效期/适用范围，审查冲突；问题期间不明时接受澄清，资料不足时补充资料。

网页采集抓取公开正文后直接排入索引并保存版本；先确认目标 URL 和内容可信度，不要把成功索引当作事实认证。索引分块与原始文件不是同一份备份；当前知识导出不能替代原 PDF/DOCX 文件归档。实现细节见[RAG 全流程](rag.md)。

## 任务、日程和记忆

任务支持项目、父子层级、标签、优先级、截止与状态视图。工作区新增字段不表示 Agent 的旧 createTask 参数也已扩展；复杂字段可在任务页编辑。日程支持重复规则、区间查看、冲突检查和日历交换；导入先预览，再按摘要确认，避免重复导入。

页面提醒可标记已读；Web Push 需服务端 VAPID、HTTPS/受信上下文、浏览器授权与订阅。HTTP/SSE 正常不等于后台通知已送达。标记已读与外部投递 ACK 是不同动作，见[提醒机制](reminder-stream-and-queue.md)。

长期记忆位于知识库的记忆区域（旧 `/memory` 地址会跳转）。可显式保存、修改、置顶和删除；自动沉淀默认关闭。记忆会按相关性/新近性预算注入，不等于全部聊天历史，也不自动成为知识问答的引用证据。

## 定时报告、运行中心与维护

定时报告运行受限只读工作流，不是可任意执行命令的 Agent。运行中心汇总未完成运行、确认、工具轨迹和用量；先用它核查失败工具与已完成操作，再决定是否重试。

数据导入导出、检查与演练报告在设置的数据区域；旧 `/maintenance`、`/usage` 地址会跳转到对应新区域。业务 JSON 导出用于交换，不等于数据库+附件+加密主密钥完整备份。导入有空库/格式等约束，先备份再操作，见[运维](operations.md)。

遇到问题保留 `X-Request-Id`、Run/任务 ID、发生时间和脱敏错误。不要提交完整对话、Cookie、模型密钥或 `.env`；按[贡献指南](../CONTRIBUTING.md)报告。
