# 对话快捷指令

在发送框输入 / 打开候选菜单。上下方向键选择，Tab 或点击候选只补全，Enter 按当前发送偏好执行。中文输入法选词不会执行；Esc 关闭候选。指令不通过对话模型解析，而是直接调用 Java / Go 中已有的工具。

| 指令 | 行为 |
| --- | --- |
| /help | 显示用法 |
| /tasks [关键词] | 查询最多 20 条任务，结果中可查看任务 ID |
| /task 买牛奶 | 创建标题为“买牛奶”的任务 |
| /done <任务 UUID> | 完成指定任务 |
| /delete-task <任务 UUID> [更多 UUID] | 申请删除，最多 50 个 ID；仍在待确认列表中批准 |
| /calendar [YYYY-MM-DD] | 查看未来七天或本地指定日期的日程 |
| /reminders | 查询已到点、未处理的提醒 |
| /search 报销规定 | 检索知识库 |
| /tools | 读取当前后端的工具名称、说明和 JSON 参数定义 |
| /tool createTask {"title":"买牛奶"} | 按工具名及 JSON 对象直接调用 |
| /new | 新建对话 |
| /stop | 停止当前后台任务 |
| /resume | 通过已有恢复流程继续任务，保留结果核查限制 |

已注册的 MCP 工具也可通过 /tool 调用，沿用各自 AUTO / 需要确认的策略。askUser 和执行步骤变更等依赖模型运行状态的工具不在直接调用清单中。工具自身使用的嵌入检索、联网服务或 MCP 服务仍按原配置运行；“直接调用”只省去对话模型解析指令。

未知指令、无效 UUID 或 JSON 对象会明确报错并保留草稿，不会作为普通消息发给模型。要发送以 / 开头的普通文本，请输入 //，例如 //path 会发送 /path。快捷指令不接受附件；有附件时会提示并保留附件和草稿。后台任务执行中可以查看帮助、工具清单或停止任务，其余操作需先停止。

## 重试及结果

快捷操作发送前，前端先把参数摘要对应的 UUID 保存在当前标签页的 sessionStorage，仅存摘要和操作标识，不存原始参数。响应丢失或结果未知时，再次提交同一会话、同一工具及相同参数会沿用原 UUID；刷新当前标签页也保留该身份。存储不可用时不发送操作。没有自动重试写操作。

后端把 Idempotency-Key 绑定到会话、工具和规范化参数。键顺序不影响摘要，数组顺序保留。同键同内容回放原回执，同键不同内容拒绝；处理中或失败的工具记录阻止再次执行。成功、明确拒绝或已生成待确认操作后，前端后续主动提交视为新操作，使用新 UUID。原待确认记录仍由确认流程管理。

这不是跨标签页或跨浏览器的操作识别：新标签页、新会话、新 UUID 或改变参数是新的操作，不能靠这种方式重试未知结果。成功记录仍遵守保留策略（默认永久）；主动清理成功回执会缩短历史去重范围。FAILED / IN_PROGRESS 的 TOOL 执行所有权不随普通审计清理删除。

MCP 自动执行和确认执行都传递稳定的 personal-ai-os/idempotency-key 元数据。远端必须实现该元数据的去重语义，才能提供其端到端保证。远端可能已修改数据但响应丢失时，系统保留未知状态并要求核对，不宣称目标未变化，也不保证任意 MCP 服务都能端到端恰好执行一次。

工具结果在输入区上方显示；最近结果卡片属于当前页面状态，刷新后可通过原有活动记录核查。删除等待确认时，仍使用上方待确认操作处理。

## 双端接口

- GET /api/v1/chat/tools：已注册的可直接调用工具数组，每项含 name、description 和 JSON 字符串 inputSchema。
- POST /api/v1/chat/sessions/{conversationId}/tools：请求头 Idempotency-Key 为 UUID；JSON 请求体为 {"tool":"createTask","arguments":{"title":"买牛奶"}}。
- 返回统一 API envelope，data 含 requestId、tool、result 和 replayed。result 沿用 OK / DUPLICATE / REQUIRES_CONFIRMATION / REJECTED / ERROR 及原 confirmationId。
- 使用现有认证、CSRF、会话存在性检查和会话执行租约；参数对象最多 64KB；不绕过删除确认、MCP 策略或工具审计。
