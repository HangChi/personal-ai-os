# 1000 文档知识库扩充与重排消融实测

实验日期：2026-11-08，Asia/Shanghai。结果属于本次固定语料、题集、模型和构建，不外推为整库或生产全链路验收。

本次固定候选池下，重排将 P@1 从 78.13% 提高到 98.44%、R@5 从 92.19% 提高到 100%；参考答案事实级 F1 从 0.3598 提高到 0.7422。事实 F1 的配对增量区间为 +28.43 至 +48.06 个百分点。忠实度均值提高，但其区间跨过 0，不能据此断言稳定提升。额外重排的中位耗时为 0.280 秒。

## 1. 实际入库

现有知识库由 100 篇增至 **1000 篇**，新增 900 篇正文、14,283 个分块，总计 **14,751 个分块**。新增正文按后端口径为 13,194,572 字符，13,327,480 字节。

| 构成 | 文档数 | 收录范围 |
| --- | ---: | --- |
| 新增掘金 | 5 | 公开完整博客正文；保留原作者、URL、时间及正文哈希 |
| 新增 Python 3.14 官方文档 | 450 | 官方 HTML 离线包中的独立正文页 |
| 新增 PostgreSQL 17.9 官方文档 | 445 | 官方 PGDG 文档包中的独立 HTML 正文页 |
| 保留原掘金来源索引卡 | 80 | 来源卡，不是博客正文 |
| 保留原合成场景 | 20 | 合成测试资料，不是生产事实 |

掘金后续公开页虽返回 HTTP 200，却没有可用正文，采集器按规则停止。因此本次没有宣称采到 900 篇掘金，也没有用空白页、重复文本或短摘要凑正文数。正文仅存本地私有缓存，不提交到仓库；去除导航后保留正文，长页未截断为多个伪文档。

核验：原 100 篇文档的元数据及分块内容哈希保持不变：**True**；文档分块计数与实际存储一致：**True**；新增来源元数据 900 条；OpenSearch 待同步 **0**。第 0、24、49 页各返回 20 条，总数均为 1000。

首次导入有 8 篇受到嵌入批量限制影响，共保留 9 个终态失败任务。提供商实际提示每批最多 25 条，原 Java 仅按 token 分批。现增加每批最多 16 条限制，并保留 token 边界及顺序，覆盖异步索引、替换和数据导入。所有新增文档最终均成功；失败记录未删除，重提先核验原任务终态及无残留文档。

同步新增仍使用 VectorStore 自身写入路径，不将本次修复外推到所有 Java 入口。资料后台审查属于另一流程，入库完成和检索可用不表示所有资料已经事实审核通过。

采集结束后，将新增 5 篇掘金文档的来源范围文字由通用“官方技术参考”前缀校正为“掘金作者博客”，原作者及 URL 保留，正文与向量未变化。本消融生成提示词不注入这个来源范围字段；回答和 RAGAS 均继续使用冻结证据。校正和最终内容哈希核验回执保留于私有缓存。

## 2. 对照设计与题集

固定 130 题：64 道语义正例、6 道无答案负例，以及单独报告的 60 道标题定位题。语义题由原 40 题加新增 30 题构成；新增包含 Python、PostgreSQL、掘金正文各 10 题。全部参考答案、支持文档与原文锚点在采集回答前冻结，支持来源共覆盖 107 篇不同文档（含定位题）。这些是选定样本，不是对 1000 篇逐篇验收。

| 设置 | 本次值 |
| --- | --- |
| 生成模型 | qwen3.8-flash；临时库 temperature=0 |
| 嵌入模型 | qwen3.7-text-embedding-flash |
| 重排模型 | qwen3-rerank |
| RAGAS | 0.4.3，裁判 qwen3.8-flash，temperature=0 |
| 候选 | 每题业务混合召回一次，保留 RRF 前 40 个分块，冻结同一池供两组使用 |
| 无重排组 | 直接保留 RRF 顺序，无聊天模型或交叉编码器重排 |
| 重排组 | 同一池调用已配置交叉编码器，每块最多 2000 字符，校验返回索引完整唯一及分数 |
| 上下文 | 两组均先每篇取一块，再补第二块；最多 5 块、每篇最多 2 块 |
| 生成 | 复用实际 KnowledgeQaService 提示词、生成实现与引用组装；交替两组顺序，串行采集 |
| 隔离 | 独立临时 PostgreSQL / OpenSearch / 本机 Java 实例；关闭缓存和后台副作用 |

这是控制候选池的重排消融，不是完整生产 RAG pipeline A/B。查询改写、证据精审、来源冲突守卫和完整拒答策略不参与该消融。现有生产 pipeline 关闭交叉编码器后仍会用聊天模型重排，所以没有把该开关当作“无重排”。评测 Java 入口只在私有隔离进程编译注册，不装入产品 JAR。

首次快照预检因正常后台资料审查更新来源状态而失败，已保留原失败输出；随后临时暂停原实例后台审查，重新冻结；另一次预检发现并修正隔离入口的重复注册，正式采样前没有生成任何回答。最后恢复原设置。未通过放宽快照校验来忽略来源变化。

## 3. 检索精度、召回与排序

以文档为排序单位，按首次出现的分块去重。P@k=前 k 篇中已标注支持文档数/k，R@k=已命中支持文档数/全部已标注支持文档数；不足 k 仍用固定 k 作精度分母。以下为 64 道正例的逐题宏平均。

相关性标签是已知支持来源，不是对所有候选的穷尽人工判断，未标注但实际相关的官方文档可能被计为非相关，因此本表精度偏保守。多数题只有一篇标注支持文档；本题集按这些标签计算的 P@5 理论上限为 20.625%，不应把低于 100% 的 P@5 直接解释为低答对率。

## 4. RAGAS 五项

在 64 道语义正例上分别评两组。Faithfulness 衡量回答受上下文支持的程度；FactualCorrectness 使用参考答案的事实级 F1；ContextPrecision/Recall 衡量上下文对参考答案的有效性与覆盖；AnswerRelevancy 反向生成 3 个问题，再用当前嵌入模型计算相关性。它们不是同一个“准确率”。

| 指标 | 无重排（有效/应评） | 重排（有效/应评） | 配对差值及 95% 区间 |
| --- | ---: | ---: | --- |
| faithfulness | 0.9145（64/64） | 0.9477（64/64） | +3.31 pp；[-3.70, +10.00] pp，n=64 |
| factual_correctness | 0.3598（64/64） | 0.7422（64/64） | +38.23 pp；[+28.43, +48.06] pp，n=64 |
| context_precision | 0.4021（64/64） | 0.9112（64/64） | +50.91 pp；[+39.50, +62.24] pp，n=64 |
| context_recall | 0.5442（64/64） | 0.9219（64/64） | +37.77 pp；[+28.05, +47.75] pp，n=64 |
| answer_relevancy | 0.5131（64/64） | 0.8056（64/64） | +29.25 pp；[+19.37, +39.81] pp，n=64 |

裁判与生成使用同一模型，存在同模型偏差；AnswerRelevancy 又复用当前嵌入模型，不能视为完全独立裁判。RAGAS 默认英文提示词处理中文问题及中英混合正文。失败/缺失不伪造为分数；空上下文的上下文相关指标记 0 并保留原因。重试追加记录，汇总使用同一题/组/指标的最后结果，原失败不删除。

本轮 640 项均得到有效分数，没有缺失或评分失败。Faithfulness 配对区间跨过 0，其均值改善不应解释为已证实稳定提升；其余所列质量指标仍受同模型裁判及样本选择的限制。

## 8. 具体案例

Go GC 工具题（jj-gc-tools）：包含 gctrace、pprof、ReadMemStats 的正确分块在 RRF 池内排第 40，重排后升至第 2。但重排第 1 块也属于同一正文文档；本消融先每篇取一块，5 个不同文档填满上下文后未再加入第 2 块。两组最终上下文均缺少三个工具名，均回复资料不足。文档级检索已命中，不等于答案分块已经送给生成器。这是本次消融选择规则的限制，不能直接归因于完整生产 pipeline。

历史版本题（policy-october）：RRF 中支持旧版的文档排第 1，重排后排第 2、首位变成新版，文档排序表面退步；但重排选择的旧版分块包含问题所需事实，回答给出 40 份、8000 字符、8 分钟及 2026-10-01 至 2026-10-31 的合成旧版范围，RRF 组则拒答。因此排序指标和回答事实覆盖需要分别衡量；这些数字只描述合成案例，不是本项目生产配置。

基础问答在答案没有显式引用编号时会回退返回全部候选引用。因此无编号的资料不足答复也可能使标记与引用列表一致性检查失败；这和伪造分块正文是两种不同问题。高忠实度也不能单独证明已回答完整问题。

## 9. 解读边界

- 本实验只能回答“在这套语料和题集上，固定候选池后重排带来什么变化”，不能替代完整生产 RAG、端到端守卫、并发稳定性或人工整库审核。
- P/R 使用已知支持来源；RAGAS 是模型裁判；确定性要点检查是启发式。三种证据分别保留，不拼成一个虚构的总准确率。
- 资料领域偏技术文档、语言混合；原题与标题含明显主题词。5 篇掘金、10 道掘金问答的代表性有限，未进行多轮独立抽样或独立人工盲评。
- 没有将旧 100 文档报告分数直接当作新增 1000 文档的同条件基线；本表两组来自同一次新快照。
