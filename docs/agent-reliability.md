# Agent 执行边界与评测

项目保持单用户、单实例；交互式任务通过 SSE 响应，不引入多租户或持久化任务队列。

## 调用预算

| 配置 | 默认值 | 含义 |
| --- | --- | --- |
| `AI_TOOL_MAX_CALLS_PER_TOOL` | 3 | 同一轮单个工具的最大调用次数，包含正常查询 |
| `AI_TOOL_MAX_TOTAL_CALLS` | 12 | 同一轮所有工具的最大调用次数 |
| `AI_TOOL_ON_LIMIT_EXCEEDED` | `throw` | 应用将框架超限异常转换为 `50203` 并结束本轮，不再交回模型继续循环 |
| `AI_AGENT_MAX_MODEL_CALLS` | 12 | 独立的每轮模型请求硬上限，包含上下文溢出后的请求重试 |
| `AI_AGENT_MAX_CONSECUTIVE_FAILURES` | 2 | 连续工具失败/参数拒绝达到上限后停止 |
| `AI_RETRY_MAX_ATTEMPTS` | 1 | 框架模型请求默认只尝试一次；启动期公共/聊天/嵌入和运行期 OpenAI SDK 均禁用隐式重试 |
| `AI_MODEL_MAX_CONCURRENT_REQUESTS` | 4 | 全局前台模型请求的在途上限，SSE 从建立到结束持续占用一个许可 |

同工具同参数失败后，本轮不再执行它；允许在失败预算内修正参数或换工具。新一轮创建全新的预算。
独立预算随 ToolContext 传递，不靠线程局部变量，也不会因消息窗口裁剪而归零。
预算触发后错误码为 `50203`，沿既有 SSE 失败路径取消上游、释放资源并记录中断回答。
聊天历史保留工具停止原因；本轮已完成的写入不会因后续失败而撤销，重试前应先查看执行记录，避免重复创建。
模型配置的环境变量覆盖默认值时，以部署配置为准；修改后重启服务生效。

## 工具、计划与恢复

工具仍由模型根据名称、说明和参数 Schema 选择。未证明选型准确率不足之前，不增加额外路由模型。
每轮系统上下文从服务端时钟提供当前时间、日期、日历时区及明天日期。相对日期以日历时区解释；无需联网校时或读取文件时间。
日历时区沿用服务端 JVM 时区，本地运行使用系统时区，容器通过 `TZ` 配置；部署时应与个人日历所在时区一致。
连续安排日程时，省略日期的后续时段承接前文用户明确指定的日期；指代不明确时询问，不因为今天的时段已过就自行顺延。
写操作的完成说明必须依据本轮成功工具结果。对包含日程或时间信息的输入，服务端先缓冲并检查模型的明确创建成功表述；
没有本轮成功的 `createCalendarEvent` 结果时，丢弃该表述并最多纠正一次，让模型补发正常工具调用。
纠正仍虚报时，返回「尚未创建」；被丢弃的虚报不推送给前端，也不保存到聊天记忆。纠正请求仍计入模型调用预算。
该保护匹配常见中英文完成表述，不能替代语义评测；普通聊天仍流式输出，日程操作回复要等待校验。
计划的开始和完成都校验当前顺序；失败步骤须先重启或显式跳过，不能直接声称完成。

MCP 的只读回调每次从注册表获取当前客户端；连接异常标记不可用，手动重连后同一回调可恢复。
业务参数错误保留健康连接。旧连接的迟到异常不会关闭新连接，重连会先关闭旧客户端。
写操作不自动重放，仍经过人工确认与幂等检查。
新 server 或工具 Schema 变化仍需要重启以重新发现工具，重连用于恢复已发现的工具。

全局准入覆盖对话、知识库检索/问答/上传/替换、语音转写及模型探测入口。
后台摘要与记忆继续使用独立的有界执行器，不计入前台请求许可。
长对话保留原始历史，按预算选窗口、滚动摘要；摘要保真通过下述可选长历史评测验证。

## 调试追踪

一次请求沿 `requestId → conversationId / turnId → 模型请求序号 → 工具名 / outcome / argumentsDigest` 关联日志。
工具审计 API 额外返回 `turnId` 和 `argumentsDigest`，可定位对应轮次；不会返回原始工具参数。
聊天里的各条回答保留各自的工具轨迹。前端按用户消息和助手回复的时间区间关联记录，再按 `turnId` 保留该区间的最新尝试；
新回复不会继承上一轮工具，也不会混入重试前的失败。加载更早消息时同步补齐审计分页；历史记录仍可从活动页完整查询。
没有对应用户消息的分页首条助手回复暂不猜测归属，加载更早一页后再关联。
每轮模型上下文读取当前会话的待确认数量及最近确认状态，已确认、已取消、已过期、执行失败都不会继续被计作待确认。
历史回复的文字保留当时快照；其旁边的人工确认反馈和工具标签展示实时状态。本轮新申请仍以新工具结果为准。
结合已有 Token 用量、工具耗时和计划状态进行排障。这是单实例日志关联，不是持久化全量 Prompt 回放。

## 评测

自动回归验证循环硬终止、同参数失败不重试、连续失败停止、计划跳步拒绝、真实 MCP 断连重连及异步许可释放：

```bash
cd backend
./mvnw -B verify
```

真实模型评测验证工具选择、闲聊不调用工具、删除先确认、创建实际落库，并输出成功率、工具调用/失败次数、耗时 P50/P95 与输入 Token：

```bash
python3 scripts/eval/agent-eval.py --output /tmp/agent-eval.json
# 可选：超过近期消息窗口后能否找回早期事实，会额外调用模型
python3 scripts/eval/agent-eval.py --long-history --output /tmp/agent-eval-long.json
# 评测器本身的离线回归，不调用模型
python3 -m unittest discover -s scripts/eval -p 'test_agent_eval.py'
```

启用认证时用 `AGENT_EVAL_COOKIE` 提供已登录 Cookie；报告不记录 Cookie、Prompt 或上游原始错误。
评测会创建唯一前缀的测试会话和任务，结束后取消本轮确认并清理测试数据，不清库。
应使用专门的测试配置运行：Agent 仍具有其配置中开放的能力，评测器不能替代工具执行边界。
知识场景需要可用的嵌入配置；未配置造成失败也会计入结果，不静默跳过。
输入 Token 可能是估算，且不包含摘要及输出成本；单次六场景延迟仅供回归比较，不代表压测结论。
对比模型或 Prompt 时固定场景与环境，重复多轮查看波动；不将工程测试通过率当作模型任务成功率。
